生产模型体系

主模型

FloodNet Binary Aug

负责常规航拍和水域分割，是每次请求首先执行的模型。

onnx/floodnet_binary_aug_yolov8m_1024.onnx

输入 1024，输出通道 37，置信度阈值 0.25。

回退模型 A

Road Flood Base

由 3908 张城市道路积水/无水数据训练，对道路洪水和斜视场景召回更强。

onnx/waterlogging_yolov8m_base_640.onnx

输入 640，级联置信度阈值 0.15。

回退模型 B

Hard Finetune

困难样本微调模型，与 Base 取像素交集，约束跨域误报。

onnx/waterlogging_yolov8m_hard_finetune_640.onnx

输入 640，仅在满足级联条件时惰性加载。

推理决策流

1. 主模型推理

Letterbox → NCHW float → ONNX → NMS → proto mask 解码 → 二值掩膜。
→

2. 场景判定

主模型面积低于 0.5%，且长宽比至少 1.15，才触发道路模型级联。
→

3. 保守共识

Base ∩ Hard Finetune；交集面积达到 0.5% 才替换主结果。
当前级联规则 
trigger =
  cascade_enabled
  AND primary_area_ratio < 0.005
  AND max(width / height, height / width) >= 1.15

fallback_consensus = base_mask AND hard_finetune_mask

accept =
  fallback_consensus_area_ratio >= 0.005

方形航拍图默认不进入道路级联，防止道路模型在草地、屋顶或阴影区域产生额外误报。

大图处理与软分块融合

大尺寸或长矩形图像可以切成 1024 像素 tile，默认重叠 256 像素。 每个 tile 返回浮点概率图，重叠区域先求平均，再与整图结果进行软融合。 

tiled_probability = average(stitched_tile_probabilities)

combined_probability =
  max(coarse_binary, 0.7 * tiled_probability)

final_mask =
  postprocess(combined_probability >= 0.5)
为什么不用硬门控： 旧逻辑要求 tile 预测必须落在整图粗掩膜附近，因此整图漏掉的水域永远无法由 tile 补回。 当前软融合允许高置信度局部结果存活，同时通过 0.7 权重、最小面积和后处理控制误报。
