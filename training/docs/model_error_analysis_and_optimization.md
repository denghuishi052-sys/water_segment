# 水体分割模型结果分析与优化方向

## 1. 背景

本文基于当前项目中三类模型的测试结果，以及若干额外图片的单图预测结果，分析当前模型在哪些图像上容易分割较好，在哪些图像上容易漏检或误检，并给出几套可以实际落地的优化方向。

对比模型如下：

| 模型 | 说明 |
| --- | --- |
| base | 原始主模型：`runs/segment/runs/segment/waterlogging_yolov8m_640_b8-3/weights/best.pt` |
| balanced_freeze | 第一版 hard balanced 微调模型，负样本约束过强 |
| recall_15fp | 最新召回增强微调模型：`waterlogging_yolov8m_hard_recall_freeze` |

整体 test 集指标：

| 模型 | micro IoU | micro Dice | precision | recall | FP images | FN images | 结论 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | --- |
| base | 0.8539 | 0.9212 | 0.9172 | 0.9253 | 4 | 8 | 总体最稳定 |
| balanced_freeze | 0.7312 | 0.8447 | 0.9225 | 0.7790 | 0 | 80 | 过于保守，漏检严重 |
| recall_15fp | 0.8415 | 0.9139 | 0.9242 | 0.9038 | 7 | 3 | 显著降低漏检，但部分场景误检增加 |

## 2. 容易分割较好的图片类型

### 2.1 地面视角的大面积洪水道路

代表图片：

- `Flood_1058.jpg`
- `Flood_1028.jpg`

base model 在 `conf=0.25` 下表现较好：

| 图片 | base 检出 | 置信度 | 预测面积占比 | 观察 |
| --- | ---: | --- | ---: | --- |
| Flood_1058 | 2 个 | 0.8972, 0.2838 | 35.30% | 主水面检出较完整，但边缘有少量地面/阴影误分 |
| Flood_1028 | 1 个 | 0.8728 | 36.14% | 主水面分割较完整，整体可用 |

这类图片容易分好的原因：

- 水面占图像比例较大；
- 水体纹理连续，边界较清楚；
- 视角接近训练集中常见的地面积水/道路积水场景；
- 水体和非水体之间的颜色、亮度、纹理差异较明显。

可视化结果：

- `runs/single_image_tests/base_flood_1058_1028_1025_conf0p25/Flood_1028/prediction_panel.jpg`

示例：`Flood_1028.jpg`，base model 能较完整覆盖道路积水区域。

![Flood_1028 base prediction](../runs/single_image_tests/base_flood_1058_1028_1025_conf0p25/Flood_1028/prediction_panel.jpg)

### 2.2 大面积、均匀、边界清楚的航拍水体

代表图片：

- `6616.jpg`

base model 能较干净地检出左侧大面积水体；最新 recall 模型虽然也能检出水体，但更容易在树冠/阴影处出现额外误报。

这说明：对于“水面颜色稳定、面积大、岸线明显”的航拍图，base model 仍然有较好的泛化能力。

## 3. 容易分割不好的图片类型

### 3.1 高空航拍图中的大水面或水库/河道边缘

代表图片：

- `8945.jpg`
- `10163.jpg`
- `7370.jpg`
- 微信图片 `20260602144629_184_4.png`

现象：

- `8945.jpg`：base 只检出右下小水池，左下大水面漏检。
- `10163.jpg`：base 空预测。
- `7370.jpg`：base 检出的是房屋/屋顶附近小块，右侧大水体没有检出。
- 微信图片：base 即使降低到 `conf=0.02` 仍然没有检出；recall 模型在低阈值下只检出小块或产生粗糙结果。

示例：`8945.jpg`，base model 只检出右下小水池，左下大水面漏检。

![8945 base prediction](../runs/single_image_tests/base_batch_8945_10163_7889_7370/8945/prediction_panel.jpg)

示例：`7370.jpg`，base model 对右侧大水体漏检，反而在建筑附近产生小块误检。

![7370 base prediction](../runs/single_image_tests/base_batch_8945_10163_7889_7370/7370/prediction_panel.jpg)

可能原因：

- 这些图的原始分辨率明显高于训练集常见尺寸，例如 `4000x3000`、`4592x3072`；
- YOLO 推理时整体 letterbox 到 `imgsz=704`，超大图会被强烈压缩，水边界和局部纹理被压得很细；
- 航拍大水面有时纹理过于均匀，模型可能更像在找“积水局部纹理”，而不是整片湖/河/蓄水区域；
- 岸线、浅滩、泥地、草地和浑水颜色接近，容易降低置信度。

### 3.2 草地、湿地、阴影、树冠场景

代表图片：

- `7889.jpg`
- `6616.jpg` 右上树冠/阴影区域
- `8945.jpg` 缩放后草地/岸边误报

现象：

- `7889.jpg` 本身没有明显水体，base 空预测是合理的；但最新 recall 模型会在草地/树影区域产生大面积误报。
- `6616.jpg` 中 recall 模型会把右上树冠/阴影附近识别成水体。
- `8945.jpg` 先缩到 800 宽再用 recall 模型预测，检出的主要是草地/岸边，而不是水面。

示例：`7889.jpg`，本身没有明显水体，但 recall 模型在草地/树影区域大面积误报。

![7889 recall resize false positive](../runs/single_image_tests/recall_model_resize_compare/7889/pre_resize_w800/prediction_panel.jpg)

示例：`6616.jpg`，recall 模型检出左侧大水体，但右上树冠/阴影区域也被误检。

![6616 recall false positive](../runs/single_image_tests/recall_model_resize_compare/6616/native/prediction_panel.jpg)

可能原因：

- 最新 recall 微调数据为了降低 FN，提高了 hard FN / low IoU positive 的权重；
- 召回增强后，模型对低置信度水体候选更敏感，但也更容易把暗色树影、湿草地、草地纹理当成水；
- hard negative 中仍缺少足够多的“高空草地/树影/岸边/浅滩”负样本。

### 3.3 雪地、反光、冬季积水

代表图片：

- `Flood_1012.jpg`

base model 默认 `conf=0.25` 完全漏检；降低阈值后：

| conf | 检出数量 | 预测面积占比 | 观察 |
| ---: | ---: | ---: | --- |
| 0.20 | 1 | 3.00% | 较干净，但只覆盖右侧一小段水面 |
| 0.15 | 1 | 3.00% | 与 0.20 基本一致 |
| 0.10 | 2 | 20.05% | 覆盖更多水带，但明显误分雪地 |
| 0.02 | 8 | 21.48% | 更碎、更脏 |

示例：`Flood_1012.jpg`，base model 在 `conf=0.10` 下能检出部分水面，但前景雪地也被明显误分。

![Flood_1012 base conf 0.10](../runs/single_image_tests/flood_1012_base_low_conf/conf_0p1/prediction_panel.jpg)

可能原因：

- 雪地高亮区域、冰面、水面反光混在一起；
- 训练集中类似“雪地 + 冬季积水”的样本不足；
- 水面在这张图中较窄且被树干、阴影遮挡，模型默认置信度偏低。

### 3.4 林地、木栈道、暗水面

代表图片：

- `Flood_1025.jpg`

base model 在 `conf=0.25` 下漏检；recall 模型在 `conf=0.25` 下检出一小块，但主要落在木栈道区域，像误报。

示例：`Flood_1025.jpg`，recall 模型检出的小区域主要落在木栈道上，不是理想水面分割。

![Flood_1025 recall prediction](../runs/single_image_tests/recall_flood_1058_1028_1012_1025_conf0p25/Flood_1025/prediction_panel.jpg)

可能原因：

- 水面被树木、栏杆、人物遮挡；
- 水体颜色接近木板和阴影；
- 训练集中类似森林、栈道、暗水体、小水面碎片的正负样本都不足；
- 该场景与主要训练分布差异较大。

## 4. 尺度与分辨率问题

测试图片分辨率：

| 图片 | 分辨率 |
| --- | --- |
| Flood_1058 / 1028 / 1025 / 1012 | 800x600 |
| 8945 / 10163 / 7889 | 4000x3000 |
| 7370 / 6616 | 4592x3072 |

训练集原始图像：

- train 图片数：3908
- 原始分辨率种类：1477
- 常见尺寸包括 `667x500`、`500x375`、`889x500`、`888x500`、`640x480` 等
- base 训练配置 `imgsz=680`

结论：

- 地面洪水图 `800x600` 与训练输入尺度更接近，因此 base model 表现较好；
- 高分辨率航拍图在整图推理时被压缩到 `704` 左右，小目标、水边界、岸线信息损失明显；
- 简单 pre-resize 到 800 宽并不稳定：有些图会检出更多，但也可能引入草地/岸边误报。

## 5. 模型训练结果带来的启示

### 5.1 balanced_freeze 为什么失败

balanced_freeze 把 FP 压到 0，但 FN 从 8 增加到 80。其主要问题是 hard false positive negative 池子只有 4 张唯一图片，却被重复采样到较高比例，模型被训练得过于保守，倾向于不输出水体。

### 5.2 recall_15fp 的优点与问题

recall_15fp 将 FN 从 80 降到 3，说明召回增强方向是有效的。但 FP 从 4 增到 7，并且在额外航拍图上出现明显草地/树影误报。

这说明：

- 微调数据比例确实影响模型的召回/精度平衡；
- 当前最佳方向不是继续盲目提高正样本或 hard FN，而是补充更有代表性的 hard negative；
- 高空航拍、湿地、草地、树影、浅滩、屋顶/道路阴影都应该作为新的 hard negative 来源。

## 6. 可实践的优化方向

### 方向 A：构建第二版 hard dataset，补足难负样本

目标：在保留 recall_15fp 低漏检优势的同时，压低草地/树影/岸边误报。

建议新增 hard negative 类型：

| 类型 | 来源 | 目的 |
| --- | --- | --- |
| aerial_grass_negative | `7889.jpg` 这类高空草地/湿地 | 抑制草地误报 |
| tree_shadow_negative | `6616.jpg` 右上树冠/阴影 | 抑制树影误报 |
| bank_mud_negative | `8945.jpg` 岸边、浅滩、泥地 | 抑制岸边/湿土误报 |
| roof_road_shadow_negative | `7370.jpg` 屋顶/道路阴影 | 抑制人造结构误报 |
| snow_negative | `Flood_1012.jpg` 雪地非水区域 | 抑制雪地误分 |

建议比例：

```text
45% normal_positive
15% hard_false_negative_or_low_iou_positive
15% normal_negative
25% hard_negative_new
```

其中 `hard_negative_new` 不应只重复少数图片，应该优先保证唯一图片数量。若图片少，可以从每张图中裁剪多个局部 patch，但需要避免同一张图占比过高。

适用场景：

- 当前最需要解决误报；
- 希望保留 recall_15fp 的低漏检能力；
- 已经能收集/标注这些失败场景。

### 方向 B：按场景分模型或分阈值策略

当前地面洪水图和高空航拍图表现差异很大。可以考虑推理时根据图像类型使用不同模型/阈值。

建议策略：

| 场景 | 推荐模型 | 推荐阈值 | 说明 |
| --- | --- | --- | --- |
| 地面道路大面积积水 | base 或 recall_15fp | 0.25 | 两者都可用，base 更稳 |
| 雪地窄水带 | base | 0.15-0.20 | 0.10 召回更高但误分雪地 |
| 高空航拍大水体 | base 优先 | 0.25 或 tiled inference | recall 容易草地误报 |
| 高空草地/湿地无水图 | base 优先 | 0.25 | recall 误报风险高 |
| 林地/木栈道暗水面 | 需要新训练 | 暂无稳定阈值 | 现有模型都不理想 |

适用场景：

- 不想马上重训；
- 可以接受推理流程中加入简单场景判断；
- 需要尽快提升实际使用效果。

### 方向 C：高分辨率航拍图使用 tiled inference

对于 `4000x3000`、`4592x3072` 的图，整图缩到 `704` 会损失局部细节。更合理的是切片预测：

```text
tile size: 1024 或 1280
overlap: 20%-30%
conf: 0.25
merge: mask union + NMS
```

优点：

- 保留局部岸线、水面纹理；
- 对小水体、小河道、局部积水更友好；
- 比简单提高 `imgsz` 更省显存。

风险：

- tile 会丢失全局上下文，可能增加局部误报；
- 需要更严格的后处理，例如最小面积、长宽比、区域连续性过滤；
- 对大面积湖面可能需要合并多个 tile 的结果。

适用场景：

- 主要输入是高分辨率航拍图；
- 需要识别小尺度水体；
- 允许推理速度稍慢。

### 方向 D：增加后处理规则，减少明显误报

当前误报常出现在草地、树影、屋顶、道路阴影、雪地。可以在 mask 后处理上加一些规则。

可尝试规则：

1. 最小面积过滤：
   - 去掉面积占比过小且孤立的区域；
   - 对 `7370` 这类小误报可能有效。

2. 颜色/亮度过滤：
   - 对明显绿色草地、白色雪地、灰色道路区域做弱过滤；
   - 注意不能过滤掉反光水面或浑水。

3. 连通域形态过滤：
   - 去掉过于破碎、边界锯齿、离主水体太远的小区域；
   - 对低 conf 下的碎片预测有效。

4. 水体上下文过滤：
   - 对航拍图优先保留大面积连续区域；
   - 对地面图允许横向大面积水面；
   - 对孤立高亮/暗色小块提高过滤强度。

适用场景：

- 不希望频繁重训；
- 需要快速压低明显误报；
- 可以接受规则带来的少量漏检风险。

### 方向 E：专门补充跨域样本

现有训练集和额外测试图之间存在明显 domain gap：

- 训练图多为中低分辨率；
- 高空航拍图比例不足；
- 雪地、森林、木栈道、强反光、水面被遮挡场景不足；
- 大水域、湖泊、河道和“城市积水”外观差异较大。

建议新增标注集：

| 类别 | 建议数量 |
| --- | ---: |
| 地面道路洪水正样本 | 50-100 |
| 高空航拍大水体正样本 | 50-100 |
| 高空草地/湿地负样本 | 50-100 |
| 雪地/冰面/反光负样本 | 30-50 |
| 林地/木栈道暗水体正负样本 | 30-50 |
| 岸边泥地/浅滩/湿土负样本 | 50-100 |

训练建议：

```text
model: 从 base best.pt 或 recall_15fp best.pt 出发
freeze: 10
imgsz: 704 或 896
lr0: 0.00005-0.0001
epochs: 30-50
batch: 根据显存设置
```

如果目标是减少误报，建议从 recall_15fp 出发，加入更多 hard negative；
如果目标是保持总体稳定，建议从 base 出发，加入召回不足的 hard positive 和一批 hard negative。

## 7. 推荐实施顺序

### 第一阶段：不重训，做推理策略对比

1. 对高分辨率航拍图测试：
   - base `imgsz=704`
   - base `imgsz=1024`
   - base tiled inference
2. 对地面洪水图测试：
   - base `conf=0.25`
   - base `conf=0.15`
   - recall_15fp `conf=0.25`
3. 输出每组的 FP/FN 代表图。

目的：先确认是否能通过推理策略解决一部分问题。

### 第二阶段：构建 hard negative + hard positive 小规模数据集

建议配比：

```text
40% normal_positive
20% hard_false_negative_or_low_iou_positive
20% normal_negative
20% new_hard_negative
```

如果误报仍然明显，可提高 `new_hard_negative` 到 25%-30%。

### 第三阶段：训练 recall-stable 模型

推荐目标：

- FN images 不高于 base；
- FP images 接近 base；
- gt_positive_macro_iou 接近或超过 base；
- 额外航拍/雪地/林地图不出现明显灾难性误报。

这比单纯追求 test 集 micro IoU 更符合当前实际需求。

## 8. 当前结论

1. base model 在原 test 集上总体最稳定，也更不容易在草地/航拍负样本上大面积误报。
2. balanced_freeze 过度抑制预测，虽然没有 FP，但 FN 激增，不适合当前目标。
3. recall_15fp 有效降低了 test 集漏检，但在额外航拍图、草地、树影场景上更容易误报。
4. 地面大面积洪水图较容易分割，尤其 `Flood_1058`、`Flood_1028`。
5. 高空航拍、雪地、林地木栈道、岸边浅滩/湿草地是当前主要失败场景。
6. 下一轮优化的重点不应只提高召回，而应补充高质量 hard negative，并针对高分辨率航拍图尝试 tiled inference。
